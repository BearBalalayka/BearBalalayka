# Telegram-анкета с отслеживанием партнёров: локально + GitHub → Vercel

6 вопросов (вопрос 4 — три ответа, вопрос 5 — несколько проектов, вопрос 6 — гражданство РФ), Telegram username, сообщения в личный чат с ботом и перенаправление в Telegram-группу **только после успешной отправки**.

## Локальная проверка на ПК (без Vercel, без регистрации)

Нужен Node.js 22 или новее. Открой папку проекта в VS Code и выполни:

```bash
cp .env.example .env
npm run dev
```

Открой **http://localhost:3000**. Локальный сервер и статические файлы работают полностью на твоём ПК. Команда `npm run dev` автоматически перезапустит сервер при изменении серверных файлов. HTML/CSS/JS можно обновить в браузере (F5).

Для реальной отправки в Telegram **впиши в `.env` свои значения**:

```env
BOT_TOKEN=токен_бота_из_BotFather
CHAT_ID=id_твоего_личного_чата_с_ботом
REDIRECT_URL=https://t.me/+ссылка_на_твою_группу
```

Если `.env` меняется, останови сервер (Ctrl+C) и запусти снова. Без настройки Telegram интерфейс и валидация работают, но отправка вернёт ошибку конфигурации.

`CHAT_ID` — куда **бот отправляет тебе** результаты; `REDIRECT_URL` — куда **посетитель переходит** после отправки. Это разные вещи. Чтобы получить `CHAT_ID`, напиши боту `/start`, затем открой `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` в своём браузере и посмотри `message.chat.id` (если у бота нет webhook).

Команды:
- `npm run dev` — локальная разработка (Node.js, без Vercel CLI).
- `npm start` — локальный запуск без режима watch.
- `npm test` — автоматические тесты.

## Публикация через GitHub на Vercel

1. Загрузи **содержимое папки** проекта на GitHub. Файл `.env` скрыт настройками `.gitignore` — убедись, что он не попал в репозиторий.
2. На vercel.com/new импортируй репозиторий, Framework Preset: **Other**, Root Directory: корень, Output Directory: `public` (уже задан в `vercel.json`). Build Command не нужен.
3. В Vercel → Project → Settings → Environment Variables добавь `BOT_TOKEN`, `CHAT_ID` и `REDIRECT_URL` с теми же значениями, что локально. Деплой (или Redeploy после изменений переменных).
4. Vercel сам запустит API-функцию `api/submit.mjs`, а статические файлы отдаст из `public/`. Локальный сервер `local-server.mjs` Vercel не запускает.

## Редактирование

- Вопросы и варианты ответов: `public/questions.json` (оставь уникальные id `q1`…`q6`). В `q4.options` три радиоварианта; `q5.type` = `multiple`, поэтому можно отметить несколько проектов. В шестом вопросе по умолчанию варианты «Да» и «Нет». Вариант `Нет` автоматически снимает отметки с других проектов.
- Оформление: `public/index.html`, `public/style.css`.
- Логика формы: `public/script.js`.
- Серверная отправка: `api/submit.mjs`.

Токен бота остаётся на сервере. Username проверяется только на корректность формата, не на принадлежность человеку. При открытой массовой рассылке полезна антиспам-защита.

## Если кнопка не реагирует

Замените ВСЮ папку проекта этой версией, а не только `questions.json`: старый JavaScript мог содержать проверки ровно пяти вопросов. Откройте консоль браузера (F12 → Console), если появилась ошибка. При незаполненной анкете сообщения подсвечиваются красным. При проблеме с `BOT_TOKEN`/`CHAT_ID` появляется ошибка и перенаправления нет.


## Отслеживание: от кого пришёл посетитель

Дай каждому рекламодателю или партнёру собственную ссылку **на один и тот же сайт**:

- `https://ВАШ-ПРОЕКТ.vercel.app/?ref=ivan`
- `https://ВАШ-ПРОЕКТ.vercel.app/?ref=anna`
- `https://ВАШ-ПРОЕКТ.vercel.app/?ref=partner_03`

При отправке анкеты бот добавит в сообщение строку **«🔗 От кого пришёл: ivan»**.
Если метки нет, бот напишет **«без метки»**.

Метка хранится во вкладке браузера через `sessionStorage`, чтобы не пропадать при обновлении страницы. Если в этой же вкладке перейти по другой партнёрской ссылке, запоминается последняя полученная метка. Допустимые значения `ref`: латиница, цифры, `_` и `-`, максимум 48 символов.

**Важно:** это отслеживает **заполненные анкеты**, а не каждый просмотр сайта. Посещения и конверсию по каждому партнёру можно считать дополнительно через веб-аналитику. Так как метка указана пользователем в URL, она не подходит как единственное доказательство источника для денежных расчётов.
